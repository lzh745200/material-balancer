# 物资均衡分配工具 · 使用手册

> 版本 v1.1.1 ｜ 完全离线运行 ｜ 支持 Windows x64 与麒麟 V10 / Linux ARM64
>
> 这本手册面向**使用者**（不需要任何编程知识）。开发与代码结构请看
> [项目文件结构说明.md](项目文件结构说明.md) 与 [README](../README.md)。

---

## 1. 这是什么

把一份物资清单（名称 + 单价 + 数量）**尽量公平地分配给一群人**，
并自动生成可以打印出来签字的 A4 表格。

典型场景：年会奖品、工会福利、应急物资签收、班级/团队物品分发——
凡是「人人有份、还要公平、还要签字」的场合都适用。

三个核心承诺：

- **完全离线**：不联网、不注册，数据只留在你的电脑上；
- **算法保证公平**：最大差值有量化指标，不再凭感觉；
- **装上就能用**：五步完成从清单到签字表的全过程。

## 2. 安装

### 2.1 Windows（Win10/11 x64）

安装包在 GitHub Actions 的 Artifacts 或 Release 中下载（见 README「获取安装包」）：

| 文件 | 说明 |
| --- | --- |
| `material-balancer-1.1.1-win64-setup.exe` | 安装版：双击安装，自动创建桌面/开始菜单快捷方式 |
| `material-balancer-1.1.1-win64-portable.exe` | 便携版：免安装，双击即用，适合 U 盘携带 |

> 首次运行若出现「Windows 已保护你的电脑」（SmartScreen），
> 点「更多信息 → 仍要运行」即可——这是因为安装包尚未做代码签名，应用本身完全离线无害。

### 2.2 麒麟 V10 / Linux ARM64

> ⚠️ **不要双击 deb 安装**：麒麟自带的图形安装器解析第三方 deb 时有已知缺陷
> （报 `local variable 'deb' referenced before assignment`），这是系统安装器的问题，
> 与本应用无关。请用下面两种方式之一。

**方式一：绿色版一键安装（推荐）**

```bash
tar xzf material-balancer-1.1.1-linux-arm64.tar.gz
cd 物资均衡分配工具
sudo bash install.sh        # 无 root 权限就去掉 sudo，装到 ~/.local/opt
```

安装脚本会自动：复制程序到 /opt、修正运行沙箱权限、创建桌面菜单图标。
升级重复执行即可（自动清理旧版本）；卸载执行 `sudo bash install.sh uninstall`。

**方式二：命令行安装 deb**

```bash
sudo apt install ./material-balancer-1.1.1-linux-arm64.deb
# 或：sudo dpkg -i material-balancer-*.deb && sudo apt -f install
```

### 2.3 卸载

- **Windows**：系统「设置 → 应用」中卸载，或开始菜单的卸载入口；
- **麒麟（install.sh 安装）**：`sudo bash /opt/物资均衡分配工具/install.sh uninstall`；
- **麒麟（deb 安装）**：`sudo apt remove material-balancer`。

卸载不会删除你的项目文件；草稿等用户数据在 `~/.config`（Linux）或
`%APPDATA%`（Windows）下，可按需手动清理。

## 3. 五步上手

1. **准备清单**——首次使用点工具栏「模板」下载 Excel 模板照着填；
   已有清单可直接「导入物资」。
2. **导入 / 录入**——左侧「物资清单」逐条添加或批量导入；
   中间「人员列表」逐个添加或导入名单。
3. **一键生成**——点「生成分配方案」，推荐选「贪心 + 优化（差距最小）」。
4. **微调确认**——在右侧拖拽个别物资、点击物资标签锁定特殊归属、
   用人员卡片上的开关排除请假者。
5. **打印签收**——「打印」直接出 A4 签字表，或「导出 PDF」存档。

## 4. 功能详解

### 4.1 物资清单（左栏）

- **添加**：输入名称、单价、数量后回车或点「添加」；数量默认 1。
- **编辑 / 删除 / 排序**：行内直接改；↑↓ 调整顺序（顺序即打印表顺序）。
- **搜索**：顶部搜索框按名称过滤，几百条清单一秒定位。
- **自动汇总**：标题栏实时显示「N 种 / M 件 / 总价值」。
- **数量口径**：小数数量向下取整（2.5 → 2 件），单价保留两位小数。

### 4.2 人员列表（中栏）

- **添加 / 改名 / 删除 / 排序**：与物资一致；**同名人员会被拦截**（避免签字表无法区分）。
- **批量导入**：txt / CSV / Excel 名单（每行一个姓名，自动去重、跳过表头）。
- **参与开关**：见 4.6。

### 4.3 生成方案（三种策略）

| 策略 | 特点 | 适合 |
| --- | --- | --- |
| 贪心均衡 | 瞬间完成，最贵的先给拿得最少的 | 日常快速分配 |
| 贪心 + 优化（推荐） | 反复「挪一件 / 换两件」缩小差距，差值最小 | 对公平要求高 |
| 随机模式 | 抽奖式：洗牌 → 贪心 → 优化，24 轮取最优 | 抽签发奖品，有仪式感 |

- 相同清单 + 相同设置 = 相同结果（随机模式可用固定种子复现，见设置）。
- 「允许剩余」开关：见 4.5。

### 4.4 手动调整（右栏结果区）

- **拖拽**：把物资标签从一张人员卡片拖到另一张，统计实时更新；
- **锁定**：点击物资标签加 🔒，这件的归属就固定了；
- **重新优化**：锁定后点此按钮，其余物资继续自动均衡，锁定件纹丝不动；
- **解锁全部**：恢复完全自动。

### 4.5 未分配池（允许剩余模式）

设置 → 分配与打印偏好 → 打开「允许剩余」后：

- 每人分到的价值**不超过人均**，装不下的件（如价值远超人均的大奖）留在「未分配池」；
- 池中的件可拖给任何人；已分配的件也可拖回池中（表示暂不发放）；
- 状态栏和统计区实时显示「未分配 N 件」。

### 4.6 按人排除

人员卡片右上角的开关可以**排除某人**（如请假）：本轮生成分配时不分给他，
统计、打印、导出也同步排除。重新打开开关即可恢复参与。

### 4.7 方案历史

- 每次生成都保存为一个方案（最多 30 个），列表直接对比各方案最大差值；
- 可随时「设为当前」、重命名、删除；
- 手动拖拽过的方案会标记为「手动调整」。

### 4.8 统计指标

平均价值 / 最高 / 最低 / 最大差值 / 标准差 / 未分配件数。
**最大差值超过平均价值的 10% 时**界面持续提醒——此时大概率存在单件价值
远超人均的物资，物理上无法更均衡，建议手动微调或开启「允许剩余」。

### 4.9 撤销 / 重做

Ctrl+Z / Ctrl+Y（或工具栏箭头），50 步快照，覆盖物资、人员、方案的全部修改。

## 5. 导入与导出

### 5.1 导入物资（CSV / Excel）

列：`名称, 单价, 数量`（有表头无表头均可，数量列可省略，默认 1）。
以下情况都能自动处理：GBK 编码、全角数字（１２３）、货币符号（¥5）、
千分位（1,000）、名称含逗号引号；解析不了的行会提示「跳过 N 行」。

### 5.2 导入人员（txt / CSV / Excel）

每行一个姓名；Excel 取第一列；「姓名 / Name」等表头自动跳过；重复姓名自动忽略。

### 5.3 导出

| 格式 | 内容 | 用途 |
| --- | --- | --- |
| PDF（A4 签字表） | 序号/姓名/物资/单价/数量/小计/总价值/签字栏，页脚可含页码 | 打印签收、存档 |
| Excel | 「分配明细」+「按人汇总」双表 | 财务对账、二次加工 |
| CSV | 与明细同列，UTF-8 带 BOM | 通用交换格式 |

### 5.4 打印

- 直接调起系统打印对话框；模板与 PDF 完全一致；
- 每人一块：**小块（≤14 行）整块不跨页**；大块跨页时每行重复姓名（淡色），签字归属不乱；
- 多页自动重复表头；页脚含「发放人 / 监发人 / 日期」签字位。

## 8. 常见问题（FAQ）

**Q1：麒麟上双击 deb 报 `local variable 'deb' referenced before assignment`？**
这是麒麟自带图形安装器的缺陷，与应用无关。改用命令行 `sudo apt install ./xxx.deb`
或 tar.gz 里的 `install.sh`（见 2.2 节）。

**Q2：Linux 启动报 `The SUID sandbox helper binary was found, but is not configured correctly`？**
v1.1.1 起不会出现：应用启动时会自动检测并在必要时降级为无沙箱模式。
若你仍在用旧版本，可执行 `./material-balancer --no-sandbox`。

**Q3：打开后窗口空白（多为老旧 ARM 显卡）？**
用软件渲染启动：`MB_DISABLE_GPU=1 ./material-balancer`（Linux）。

**Q4：导出的 CSV 用 Excel 打开乱码？**
不会——文件带 UTF-8 BOM。若用 WPS/旧版 Excel 仍异常，选择「数据 → 从文本导入」并指定 UTF-8。

**Q5：打印表格字体和预览不一致？**
中文字体（思源黑体）已内置在安装包中，PDF 与打印均为同一字体，不依赖系统字体。

**Q6：提示「物资总件数将超过上限（5000）」？**
为保流畅，拆分后的总件数上限为 5000、人员上限 200。可合并同类物资（用数量表达）解决。

**Q7：改了物资数量后，提示方案失效？**
这是保护机制：数量变化后原方案不再覆盖全部物资，点「重新生成」即可。
你仍可选择「继续导出」，界面会明确告诉你未分配件数。

**Q8：SmartScreen / 安全软件提示？**
安装包未做商业代码签名。应用不联网、无遥测，可放心在离线环境使用；
企业内网可由管理员统一分发便携版。

## 9. 已知限制

- 物资拆分总件数 ≤ 5000，人员 ≤ 200（性能护栏）；
- 撤销历史 50 步、方案历史 30 个（自动淘汰最旧）；
- Windows 安装包未做代码签名（首次运行需手动放行 SmartScreen）；
- 打印边距固定为 14mm/12mm，暂不支持自定义（列入后续计划）。
